## Remote Swift Package Manager

```
https://github.com/lotusflare/social-login-sdk-ios
```

Use a version tag (for example `1.0.0`) in Xcode:

**File → Add Package Dependencies… →** paste the URL → select version rule → add the `SocialLoginSDK` product.
